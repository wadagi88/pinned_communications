What they are here for

The job they hire Pinned for

Know it is handled, and be able to prove it was.

Every message on this page is judged against that sentence. If it does not help with it, or protect it, it should not be sent.

The hook
TriggerBooking confirmation lands before they have left the pod counter.
ActionDrop the parcel, or tap once to send a runner instead.

02

The SMS journey

Every moment in order, and the channel that carries it. Highlighted rows cost an SMS: 4 on a journey that works, 6 more only when something goes wrong. A row numbered + is one of those; everything unhighlighted is a deliberate decision not to spend an SMS.

Four SMS on a journey that works — three once sign-in moves to a PIN

Sign-up code, sign-in code, handover code, delivered — and the sign-in code should become a PIN. Everything between them is in-app, because the sender is holding the app. That is the whole difference between a sender and a receiver.

Access

S0

Sign-up code

The first message Pinned ever sends a sender. It carries the code, and it names the pain Pinned exists to remove.

 Not builtSMS
TriggerA new sender requests a verification code
TimingOn request · expires in 5 minutes
SourceBrief · 13 Oct
Hook · Action
Team review · 13 OctLead with the painkiller. An earlier draft — “Welcome to Pinned. Your sign-up code is …” — was correct and said nothing. It carried no name and no reason to care. Uko wapi? is the question every delivery in this city turns into: the sender ringing the rider, the receiver ringing the sender, nobody with an answer. Pinned is the answer, and the first message is the one place that claim belongs.
WarmthTheir name, and a promise in the language the problem is actually argued in.
SMS216 chars · 2 segments
Karibu Pinned, {{name}} — your answer to UKO WAPI? Sign-up code: {{otp}} Create your first trip and never ask again: watch your parcel move, minute by minute. Expires in 5 minutes. We never ask for this code by phone.
Live today19 chars · 1 segment
Your OTP code is ….
Rules
  • The sign-up code is the one code message allowed to sell. It is first contact as well as authentication. Every later code — sign-in, collection, handover — ships bare.
  • Never write “OTP” to a customer. It is a sign-up code or a collection code.
  • The expiry and the fraud line survive the rewrite. They are the two questions every code message raises, and dropping them to make room for the promise would be the wrong trade.
  • “Trip” is the sender app's own word for a delivery and its fee — see the glossary. The verb is create a trip, which is what the app's button says.
  • Two segments, and the only message in the lane where the second one is spent on warmth.
S0b

Sign-in code

A sign-in code is also a security alert. It should read like one — without claiming to know things we do not know.

 Not builtSMS
TriggerA sender signs in
TimingEach sign-in · expires in 5 minutes
SourceBrief · 13 Oct
Hook · Trigger
Team review · 13 OctNo device name. An earlier draft read “Someone is signing in on a Samsung A14”. We have no device visibility, so that sentence is void. What is left still does the job: what the code is for, how long it lasts, what to do if it was not them, and the fraud line.
WarmthReassure in the same line as the warning. Ignoring it is enough; they do not have to do anything.
SMS197 chars · 2 segments
{{name}}, your Pinned sign-in code is {{otp}}. It expires in 5 minutes. If you did not ask to sign in, ignore this message — your account stays locked and we never call or text to ask for this code.
Live today19 chars · 1 segment
Your OTP code is ….
Rules
  • Write only what the system can actually see. A security message that names a device we cannot identify is worse than one that does not, because the first time it is wrong the customer stops believing all of them.
  • Naming the device and the town is the upgrade the moment device data exists. Until then this copy stands.
  • Never include a link in a sign-in message. Every phishing SMS in this market has one.
