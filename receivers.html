01

The SMS journey

Every moment in order, grouped, and the channel that carries it. Highlighted rows cost an SMS; everything unhighlighted is a deliberate decision not to spend one. The arrow on the right of each row jumps to the copy.

Three SMS the first time, two every time after

Getting the parcel is the same two messages in every case — one when it is created, one carrying the code — and the rating ask fires once per receiver, ever. The sender type, the pickup mode and the money all change what the first message says; none of them change how many there are. Everything below the code is an exception.

02

Which message fires, and when

An individual, a business sender and a parcel handler all create the same object and all produce a different first SMS. The difference is never the number of messages — it is the origin and the status the first sentence carries, and whether money is attached. Four axes, nine cases, and the same two messages in every one of them.

01

One SMS when the parcel is created

Whoever created it, exactly one SMS goes out at creation. What varies is where the parcel is, what is happening to it, and whether a money line is attached. Nothing varies the count.

02

A second SMS only when a code is coming — and it carries only the code

The first message promises a code, so the second one delivers it, on the event that unlocks it: the payment clearing, or the parcel reaching the counter they chose. The live page already commits us to this in its own words — “Your handover code is also sent by SMS.” A receiver who owes nothing still gets a code, so a receiver who owes nothing still gets two messages.

03

The address changes the page, never the message

An unknown address is collected on the choice page, under the same link, in the same session. It does not earn an SMS of its own. A second first-contact message is the fastest way to make a stranger decide they are being marketed at.

Individual sender

One person sending to another, in the app. The trip is paid before it starts, so there is never money owed at the far end and never a choice to present. The only variable is how the parcel leaves the sender — which is exactly what the first sentence has to say.

Parcel handler

A sacco, a bus parcel office or a shop receiving on someone's behalf. One case, and the narrowest of the three: always pay-now, never goods owed, and never a Pinned pod anywhere in the chain. The parcel has genuinely travelled, which is why the opener and the register both change.

The one thing this changes. On a pay-on-delivery journey the plan was three messages — created, runner is outside, here is your code. The runner is standing at the door with a phone in their hand and the page is open in front of the receiver, so the middle one is retired. C2b is the only touchpoint on this site that is retired before it is ever built.

03

What they are here for

The person the parcel is for. Often has never heard of Pinned before the first SMS.

The job they hire Pinned for

Get the parcel without rearranging their day.

Every message on this page is judged against that sentence. If it does not help with it, or protect it, it should not be sent.
